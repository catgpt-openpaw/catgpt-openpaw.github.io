About

A small experiment in feline interface design

CatGPT is a deliberately lightweight, static web project built for fun. A cat produces nonsense keyboard input, the interface interprets it as a plausible feline question, and a curated response follows.

How it works

The public CatGPT site does not send prompts to a language model. Topics, inferred questions and responses are prewritten and stored as structured data. Short conversation flows allow a premise to continue for several turns before a new topic begins.

The result is intentionally presented with the seriousness of a conversational assistant while remaining deterministic, inspectable and lightweight.

Who made it

CatGPT was created by Dylan Lawless, a scientist and software developer working across computational biology, statistical genomics and AI systems. CatGPT is a separate, informal project and should not be confused with his scientific research or production AI work. For an example of a genuine AI model project, see here for the first (?) GPT-2 implementation written entirely in pure R.
